# Support

Use GitHub Discussions for setup questions, design discussion, and general
help. Use an issue for a reproducible bug or a scoped feature request.

Before posting:

1. remove all memory text, credentials, account IDs, repository tokens, local
   paths, hostnames, diagnostics records, and private trust state;
2. include the plugin version, operating system, Python version, and the
   content-free result category from `doctor`;
3. describe expected and actual behavior without attaching a live vault.

For vulnerabilities or any report that cannot be safely anonymized, use the
repository Security tab to open a private GitHub security advisory. Never put
secrets or private memory into a public issue.
