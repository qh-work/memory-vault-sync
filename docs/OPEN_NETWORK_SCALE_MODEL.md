# 开放网络规模与有限敌手验收模型

状态：**NOT RUN — 设计验收模型，以下新实验均未运行**。源码盘点基线为 `93c2f5d1ec94fe38cacd910d4e02df8a4f63ed11`；公开 `v0.27.0-alpha.1` 不具备本模型所要求的开放网络能力。

本文件补充 [整体架构](OPEN_NETWORK_ARCHITECTURE.md) 与 [验收计划](OPEN_NETWORK_ACCEPTANCE.md)。数值是事前验收目标，不是结果、安全证明、部署授权或规模能力声明。失败时保留证据并修订设计，不更换有利种子或悄悄降低阈值。

## 1. 判定原则

1. “敌手下资源有界”只能证明拒绝服务没有拖垮本机，不能证明开放网络可用。必须另给有限敌手下的目标发现/合法投递成功率门槛；全部请求都拒绝的实现不能通过。
2. 不采用 `min(64,8*ceil(log2(R)))` 作为增长门槛：在 R=1,000 时它等于硬请求上限64，无法区分健康查找与总在上限附近徘徊。采用跨规模成功率、实际请求、依赖轮次和时间曲线；失败不能从耗时统计中消失。

## 2. 身份、资源、在线率与工作量不能绑成同一自变量

定义：A=有效 Agent 身份数，Rr=路由节点数，Rs=存储/邮箱节点数，Rd=实际承担目录存储的节点数，pA/pR=两类在线比例，cA/cR=每维护周期身份/资源替换数，W=合法业务到达率，D=保留密文，T=保留时间，Tw=授权/撤销/重放安全窗口，μ=已测可持续服务率。一个逻辑 Agent 不是一个模型进程；一个公钥也不是一个独立运营者。

| 单变量实验 | 固定条件与取值 | 可证伪点 |
| --- | --- | --- |
| 身份远多于节点 | Rr=100、Rs固定，A=1k/10k/100k；W及活跃联系人工作集固定，同样元数据硬配额预先足够容纳最大A | 普通端点路由状态不得随A增长；目录对象可增长但必须分片，非负责节点不能保留全部A |
| 路由资源增长 | Rr=100/250/500/1k；A/Rr、每节点工作率、网络时延分布固定 | 路由查找曲线与每节点加入/维护成本；不得由测试宿主安装最近邻 |
| 存储资源增长 | Rs=16→32、64→128；Rr和对象发现负载另记 | 加磁盘必须带来实际有用容量，不能把多加router误报成存储扩容 |
| Agent在线率 | pA=1/.1/.01；Rr/Rs始终在线，W固定 | 离线者应可留下邮箱存储回执，不能要求立即validated_saved；积压受租约与容量约束 |
| 资源在线率 | pR=1/.9/.7；Agent在线，分别随机与同一故障组下线 | 分别测查找、可读副本与修复，不把A离线混入路由失效 |
| 身份创建销毁 | 固定活跃A，每周期cA=0/.01A/.1A；Tw固定，不重用身份 | 过期回收达到平台期，保留安全floor；不能为每个新身份全网更新或永久累加墓碑 |
| 资源 churn | cR=0/.01Rr/.05Rr，维持资源总量；与身份 churn 分开 | 固定维护预算内的可用性恢复和稳定邻居保留；新加入不能自动占满老节点路由槽 |
| 业务量 | W=.25/.5/.9/1.2μ；A、R、T、消息尺寸固定 | 稳态、饱和和过载分开；超过μ允许明确背压，不能伪报成功或无限排队 |
| 保留量 | T=1/10/100个合成时间单位，W/A/R固定，再做资源同比增加的对照 | D约随W*T增长是必要存储需求，不应要求有限盘恒定占用；检测每次写入扫描D的额外成本 |

目录中保留A个有效身份必然需要全网O(A)元数据，均匀分摊可约O(A/Rd)；这不等于每个节点都持有O(A)名册。身份 churn 的安全元数据还包含约 cA*Tw 的保留量。有限容量不足时拒绝新租约，不得悄悄删有效身份/历史以掩盖增长。因存储索引而产生O(log(local records))查询成本也不能误判成全网扫描。

角色可以组合，但Rr、Rs、Rd必须分别计数；增加一个纯router不自动增加磁盘或目录租约容量。
目录参与者维护独立的有界角色路由视图；普通router只保留最多4个已验证目录引介。
固定最多两种视图，不能为每个Agent/话题开一个路由表；两视图共享维护与单次查找总预算。
另测Rd/Rr=1/.1/.01，特别构造普通最近8节点均无目录角色；不能逐个过滤普通全网节点找存储。

各行先独立运行，不做昂贵全笛卡尔积。每一“维护周期”固定每节点请求/字节/时间预算；20周期意味着各规模同一局部投入，必须同时报告全网总投入，不能给大规模额外无限暖机。

## 3. 目录存储与续租不是免费的

令A_pub为实际选择公开索引、且持有有效目录租约的身份数，r_index为目录副本目标，s_record为单个物化指针大小，s_renew为一次续租的实际线字节，T_lease为续租间隔，lambda_pub为每秒创建/修改/退出的公开身份数。A_pub可以小于A；未公开身份不应被强制枚举。若续租重传整份指针，s_renew包含该指针，不能只记一个小ID。

```text
目录稳态存储约 = r_index * A_pub * s_record + 索引/租约/安全窗口开销
目录续租带宽约 = r_index * A_pub * s_renew / T_lease + churn控制与复制字节
目录续租验证工作约 = r_index * A_pub / T_lease 次协议验证 + churn验证
安全窗口额外保留量约 = r_index * lambda_pub * Tw * 每条安全记录实际大小
```

这些是规划估算，不是精确物理计量；实际协议的批处理、去重、签名缓存和复制路径分别计数，不能重复相加或用逻辑租约数代替磁盘字节。目录提供方只承担自己的租约；每节点按所接受的分片/租约计费与限速，不能要求所有节点都执行全体A_pub续租。

在固定A_pub下比较T_lease=1/10/100合成时间单位，再固定T_lease比较A_pub=1k/10k/100k，分别报告稳态存储、更新字节、签名CPU、到期任务、拒绝率及最忙节点。每组先锁定同样配额和局部维护预算；不能为了续租风暴临时延长TTL、提高配额或跳过来源验证。

Agent低在线率不能让节点伪造新的作者签名或凭空延长contact的有效期。contact签名有效期、目录资源租约和邮箱保留期限是不同义务；允许的代办续租须已有有限资源授权，不能冒充作者重新确认当前状态。不能续租时明确过期/未确认，仍有效的邮箱义务和本地长期Memory不因此自动删除。

资源不足时拒绝新租约/续租并说明实际承诺期限；不得删尚有效的旧义务、缩短本地历史保留或把未满足副本目标的指针算作成功容量。端点只为自己的公开指针支付更新成本，普通查找不下载全网续租列表。

## 4. 预先声明的有限敌手与信任条件

不能只写“10%恶意”。每次实验清单至少固定 `(H,M,K,S,B,V,bootstrap,churn)`：诚实/恶意可达路由节点数H/M、实际公钥生成尝试数K、观测网络来源组数S、攻击请求/字节预算B、事先选定目标集合V、引导条件、churn时序。恶意比例f=M/(H+M)与坏候选占比、坏路由槽占比须分别报告。

- 恶意节点使用真实合成Ed25519身份；可丢弃、延迟、选择性回答、返回自己有效签名的候选、重放旧描述符及撒谎。不能伪造诚实签名或突破本地持钥权限。
- 诚实资源通过生产join/有界维护形成已知邻接连通子图，只由夹具检查、不回填边；至少一份目标有效contact和一份合法消息副本由诚实节点保管且有有效租约。目标不在发起方初始候选，禁止测试宿主额外塞入目标地址。
- B0：最多两个不同已声明来源的诚实引导；仅首次加入可用。B1：一个诚实、一个恶意引导。B2：全部恶意且没有已知诚实路径，只测安全/隔离，不承诺可达。实验中的来源独立性来自夹具定义，不冒称两个IP就证明真实世界独立。
- 匹配健康对照使用相同身份、地址、目标、延迟和资源，只把恶意行为切为诚实。事先锁定种子17/29/43及目标列表，不因攻击成功更换种子或目标。
- 查找源分两组：首次接入即有攻击的冷端点，以及已有20周期局部状态的端点。两组分别达门槛，不能用既有邻居保护掩盖新用户无法加入。有限敌手可用性默认W=.25μ；链路有预先固定的合法流量余量，测试应用层排队/隔离，不声称抵御物理链路被完全打满。
- 先用Rr=100定位反例，再用1,000复测同模型；10,000和跨地区另列预算/未运行。固定源节点只知道有限入口，不访问夹具的全局拓扑。
- 可达性分母在运行前确定：所有合法诚实目标均计入。被攻击围困、路由预算耗尽、没有找见现存诚实副本均算失败，不能事后归为“不满足条件”从分母删除。
- general与directory角色分别记录诚实/恶意占比和引导条件。10%有限敌手门槛不能只约束Rr而允许全部Rd受控；固定各受测视图的10%上限，另报告恶意资源集中进目录的压力情形。
- 夹具可用全局图解释物理分区与合法副本是否存在，但只供断言，不能参与节点选择。额外报告全体成功率及事前定义的物理可达子集成功率，不能只给后者。

## 5. 最小合成攻击矩阵

先锁定表中实验，不把所有参数任意组合。恶意回复均计入64请求/32候选等生产预算；合法请求流固定。洪泛预算以同规模匹配健康运行的总请求数/字节为基准，最多1倍或4倍，并逐来源计量，不是每个恶意节点各获全网额度。

| 实验 | 固定干预 | 检查与可用性承诺 |
| --- | --- | --- |
| 随机恶意路由 | f=.10/.25/.40，随机ID，B0，分别丢弃和只返回恶意候选 | .10进入最低可用性门槛；.25/.40完整报告退化，不预先声称可用 |
| 目标前缀grinding | f=.10，事先锁定20个目标，K=2^12与2^16总真实生成尝试，选择最靠近目标的合法ID；B0与B1分开 | 不直接伪造坐标；报告总尝试/保留ID/目标距离及路由槽占据，所有目标仍在成功率分母 |
| 来源集中与伪多样性 | 同一上述恶意ID集，S=1与S=8合成来源组；邻居/候选上限不变 | 显示来源限制能否改善可达、是否误伤NAT后的诚实主体；S组不算物理故障域证明 |
| 引导围困与恢复 | B1与B2；先建立网络再移除原始引导；另为B2明确提供一条新诚实介绍 | B1须达到有限敌手门槛；B2未介绍前允许隔离，介绍后20周期内须实际恢复查找，不能永久锁死恶意路由表 |
| 有效签名洪泛/身份更替 | f=.10，攻击总量为健康1倍/4倍；坏主体换钥但来源与资源预算不变 | 内存/CPU/队列有界，已授权合法查询另测成功率；不能只依靠per-key限流 |
| 更新围困 | f=.10，对已见contact仅返回低版本、同序号双签及错误候选；诚实更新仍存在 | 禁止返回假freshness或假absence；报告找到正确更新比例，明确只有恶意路径时无法证明最新 |
| 恶意节点“慢而活” | f=.10，回复在单节点超时前到达但无进展；B1 | 真实合法备选路径必须取得调度预算，不能所有请求都等到总deadline才尝试诚实入口 |

首轮不加入远程真实攻击、真实云地址、付费资源或可公开复用的目标扫描；所有密钥、网络来源、受害身份和存储为本地合成。模拟source标签不是现实网络层抗Sybil验收。

## 6. 可被推翻的最低门槛与增长曲线

以下为本模型的事前目标，状态均为 **NOT RUN**。它们可能失败；失败意味着该敌手模型下“开放且可用”未通过，必须调整准入/邻居策略后重新审阅，或明确缩小能力声明，不能改成只要配额没破就算通过。

- 每规模、每种子固定1,000次合法查找，分散到至少20个源；目标/源抽样独立于成功与否。健康场景每种子成功率至少99%；引导退出后至少97%。报告样本数及置信区间，不把经验百分比当统计证明。
- 最低敌手可用性范围：f=.10，B0/B1，随机丢弃/候选污染、两种grinding预算和慢回复，单独运行每类攻击；每种子成功率至少95%，且较匹配健康对照下降不超过5个百分点。不能用总体平均掩盖20个目标中某一个被完全围困，另要求每个目标至少80%成功。
- 1倍洪泛在同样资源下也要求至少95%；4倍洪泛、f=.25/.40为压力边界，只报告实际曲线，不承诺可达。被明确拒绝的合法请求仍计失败。所有实验都必须满足安全/资源硬限。
- 合法投递另计：在成功查找到诚实有效邮箱且资源余量事前保留的子集中，`stored`至少99%；`validated_saved`只对在期限内实际重新上线的端点计，并另列离线未完成，不能混为查找成功。
- 记录每次实际请求数、签名验证次数、依赖轮次（后一次目标来自前次响应的因果深度）、候选峰值、字节、真实耗时、失败类型，以及每目标的可达性。并行3请求是1轮，不是3跳。
- 失败运行保留实际耗时/请求。另给明确命名的“含失败惩罚分数”：失败记64请求和10秒预算；这只是比较分数，不能写作真实测量耗时。同时给成功子集p50/p95和全部结果，防止早拒绝看起来更快。
- 在相同模拟链路模型（每条边固定50ms RTT，另一组固定种子10–100ms RTT；链路带宽固定，单列无额外排队的健康基线）下，画Rr=100/250/500/1,000成功率、请求/依赖轮次/耗时p50/p95；CPU与负载排队另报，真实HTTP另画，不能混图。
- 健康增长门槛：100→1,000期间，成功率下降≤2个百分点，成功请求p95增量≤`4*(ceil(log2(1000))-ceil(log2(100)))`即12，依赖轮次p95增量≤3，耗时p95≤原值2倍+100ms。固定64请求硬限仍独立适用；这些有限点门槛不证明渐近复杂度。
- 有限敌手场景除成功率门槛，匹配健康对照的成功耗时p95不得超过3倍；超过意味着虽最终可达但服务退化未通过。每个阈值在实现前锁定；要调整须保存失败证据并更新模型版本，不补跑到成功为止。

必须另外看“最大目标/最大来源”的结果。Sybil攻击可以集中在一个重要Agent；全网99%成功但该Agent始终失联，不能称“每个Agent都可用”。没有预先给出目标级承诺时，只能声明所测目标分布的平均结果。

## 7. Python/TypeScript新增共享反例（不重复已有codec矩阵）

向量以同一原始签名字节、观察到的连接来源、有限本地表、时钟与请求事件序列输入两种实现。真实JOSE不替代；跨语言一致只证明相同语义，不证明抗Sybil。

1. 合法Ed25519公钥派生坐标与描述符声明坐标不一致、256-bit XOR排序越过JS安全整数、相同距离确定性tie-break；两边拒绝/选路相同。
2. 相同签名候选从多条路径重复出现、同IP换100个key、同key换地址、攻击者把他人key与自己地址拼接；去重/来源槽位/持钥验证不把每次出现计成独立可靠路径。
3. 列表全是重复、更远或已经访问的合法候选，以及合法近邻描述符却无可用地址；结果不虚报found、不循环、不扩大候选预算。
4. 三个候选先后迟到、一个一直慢但有界回复、总截止前新诚实候选到达；每个await之后重新检查剩余工作，超时结果不写成not_found；调度顺序/输入事件固定时输出和记账一致。
5. 第9个候选、满shortlist替换、满bucket新身份、同来源额度耗尽、重试相同请求及换request_id；两个实现对同一上限有相同拒绝/退化和无越界副作用。
6. 多个独立租约竞争同一资源、身份销毁后窗口内重放、旧checkpoint恢复和节点epoch变更；拒绝不恢复权限，不让新的key重置来源/资源总账。
7. 恶意lane先介绍另一lane需要的同一诚实节点：候选保留最多两个来源位，一次实际RPC/结果共享，不让先到者夺走另一lane调度资格；总预算不增加。
8. 同来源active桶被稳定恶意节点占满后显式提供一个诚实bootstrap：允许总预算内临时持钥探测，不必先入桶；任意广告不能获得此例外。

每条包含精确结果/错误码、候选序列、剩余请求/字节、表项变化、是否发HTTP及是否写控制状态。超时工作不可变成隐藏重试；路径换入口不能改变原Memory/密文或解除投递许可。

## 8. 必须拒绝或标为尚不可实现的保证

- 无限免费密钥、无限来源/算力/带宽的敌手下仍保证任意目标可达；固定诚实占比也不足以排除特定目标前缀围困。
- 一条“诚实节点存在”的抽象路径就保证在64请求/10秒内被发现；物理连通不等于有界局部算法已知道路径。
- 全部入口被控制时自行发现诚实网络；不可达时证明全网没有记录或全部副本消失。
- 自认证、公钥数量、IP数或相同报告的次数自动证明独立运营者、真实来源、存储副本故障域或当前事实。
- R固定且A、W、D、retention无限增加仍无限容量/稳定延迟；或把短命模型实例数量当成真实独立协作能力。
- 两个有限规模点通过就证明O(log R)或互联网规模；同一设备上真实签名/HTTP通过就证明跨运营商、跨NAT或抗现实资源敌手。

结论措辞必须绑定“指定规模、指定在线/负载/retention、指定敌手预算、指定引导条件”的结果。未完成攻击可达性验收前，可以发布实验实现和已测安全边界，不能发布“已解决开放全球组网可靠性”的结论。
